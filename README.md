# OOP-Tasks

This repository is a collection of practice exercises focused on Object-Oriented Programming (OOP) using both TypeScript and Java. Each task is stored in its own folder so concepts like inheritance, encapsulation, abstraction, and polymorphism can be practiced one step at a time.

## Overview

- TypeScript tasks help practice modern OOP patterns in a JavaScript-friendly syntax.
- Java tasks help reinforce classic OOP concepts using a strongly typed, class-based language.
- Each task is independent and can be explored separately.

## Repository structure
- Each task folder may contain source files, notes, or a small README explaining the challenge and how to run it.

## Skills practiced

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- Interfaces and contracts
- Design patterns and cleaner code structure

## Tools and languages

- TypeScript
- Java
- Node.js and npm for TypeScript tasks
- JDK for Java tasks

## Example workflow

### TypeScript

```bash
npm install
npx tsc
node dist/index.js
```

### Java

```bash
javac Main.java
java Main
```

## Goal

The purpose of this repository is to build confidence in OOP by solving practical tasks and improving code quality, structure, and problem-solving skills in both TypeScript and Java.

## Notes

This repository is mainly for learning and personal practice. You can add new tasks, improve existing code, and experiment with different OOP designs as you progress.
